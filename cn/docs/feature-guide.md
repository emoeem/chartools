# Jev 聊天助手 · 功能介绍（国内版 Android）

> 包名 `com.jev.probe`，当前 2.0（开发中）· Android 11+ · 仅 ARM64 · 从源码构建，无发布安装包。
> 平台支持与构建步骤见[项目总览](../../.github/README.md)；隐私细节见[隐私政策](../PRIVACY.md)；逐版改动见[更新日志](../CHANGELOG.md)。

**一句话：挂在聊天 App 旁边的非侵入式回复副驾——读到对方最新消息，先判断局势，再起草 3 条候选回复，你看中哪条一键填入输入框。发送永远由你手动点，程序绝不自动发。**

---

## 1. 核心理念

- **先判断，再写字。** 大多数工具直接让模型编一句回复。Jev 先由判断模型给出对方真实意图、紧张程度、此刻需要什么、最该做什么，然后起草**带着这份判断**写——轻松闲聊不会被写成危机公关，吵架不会被写成插科打诨。
- **不动你的聊天软件。** 默认不 hook、不注入、不改包、不读数据库、不走任何 App 的接口或账号。只用系统无障碍服务读「屏幕上正在显示的对话」；目标 App 不给无障碍树时（如微信）退到「截屏 + 本机 OCR」，截图不出设备。
- **发送权永远在你手里。** 只把选中的回复填进输入框就停手，从不点发送按钮，不碰转账、红包、收款码。
- **接口自己配。** 判断 / 回复 / 视觉三路模型分别可填（任何 OpenAI 兼容服务商），聊天文字只发往你自己配置的接口；本分支维护者不运营中转服务器，也不做遥测。

## 2. 一条消息进来后发生什么

1. **读取**：无障碍服务读到聊天窗口里出现对方的新消息（节点树优先；微信/飞书走截屏 + 本机 ML Kit OCR）。
2. **安全闸门**（发出任何请求之前）：对方消息里出现违法内容、自伤字眼、约好的安全词（红灯）、或碰了你写下的硬边界，这一轮直接不出候选并说明原因；黄灯、疑似未成年、公共场合等信号则变成提示随提示词带给模型。
3. **判断**：判断模型回答七个问题——对方这条的真实意图（七选一）、紧张/危险程度（0–9）、对方此刻需要什么、现在最该做什么、是否该给实质内容等。判断置信度低时会标注「把握不大」，只作参考不定性。
4. **起草（先判后写）**：写作模型带着判断结果、人设、知识库和最近 20 条对话起草候选。等判断最多 2 秒，超时才盲写，判断路由挂掉也不会卡住候选。
5. **排序**：判断模型给三条候选打分排序；判断推荐的动作对应的那条会标「推荐」置顶。
6. **复查**（默认关，可开）：另一轮模型逐条核验候选——有没有答非所问、编造事实、越边界、复读——站不住的带理由重写。
7. **展示**：悬浮卡上第一条就是排序最高的候选，你点「填入」进输入框，或复制、微调、忽略。

## 3. 支持的平台

| 平台 | 状态 | 采集方式 |
|---|---|---|
| QQ Android | ✅ 全链路 | 无障碍读节点 |
| X / Twitter 私信 | ✅ 全链路 | 解析 Compose 节点的 content-desc |
| Telegram | ✅ 全链路 | 无障碍读节点（界面需中文/英文） |
| 微信 | ✅ 全链路 | 截屏 + 本机 OCR（按气泡颜色分左右） |
| 飞书 / Lark | ✅ | 无障碍读气泡位置 + 本机 OCR |
| TIM | 🧪 待验正文解析 | 无障碍读节点（viewId 混淆，随版本可能失效） |
| WhatsApp | 🧪 一对一 | 无障碍读节点（只读单聊，群聊不读） |
| 其它 App | 手动 | 长按悬浮球「截屏识别一次」整屏 OCR，不分我/对方 |

> **使用风险**：在第三方聊天 App 里使用本助手可能不符合其用户协议，账号有被限制的风险，请自行判断。可对单个 App 关掉自动分析。

## 4. 悬浮卡：你在聊天里看到的

- **贴边胶囊**：平时收成屏幕边缘一个小胶囊，跑分析时显示秒数、有判断时显示危险分（如 2/9）；拖到哪都吸回边缘，找不到时常驻通知有「唤出助手」。
- **候选第一屏**：展开就是候选回复（排序分 + 策略：稳妥承接 / 推进话题 / 换角度），判断详情折叠在「详情」里。
- **推进档位**：候选上方一排 pill——**自动 / 收着 / 自然 / 加码**。自动档按判断结果映射（局势紧→收着、约好的角色场且轻松→加码），点一下换挡，下一轮「换一组」立刻生效。
- **单条微调**：每条候选带「改短 / 换语气 / 重生成 / 复制 / 填入」，只动那一条，不重跑整轮。
- **再来一组**：「换一组」整批换（避开已给过的），「再给 2 条」在下面追加；卡上 ↻ 或通知「重新生成」随时手动触发，不用等新消息。
- **透明标注**：OCR 读的、分不清谁说的、知识库命中几条、记忆有没有开，卡上都直接说。

## 5. 人设系统：让它用你的口气说话

**人设卡**是一段键值文本，支持的键：`称呼` `关系` `语气` `语域` `主题` `情境` `硬边界` `避谈` `安全词` `黄灯` `示例`（`我：` 开头的语气样例行）`补充`。兼容 Character Card V2 的 `{{user}}`/`{{char}}` 写法。

- **语域**写「亲密」才会放开角色化称呼和情境描写——默认是关的，防止普通聊天里冒出「主人」式台词。
- **硬边界** vs **避谈**是两种东西：硬边界里的词对方一提就停整轮（如网调卡的「家人」）；避谈只约束我方措辞（如销售卡的「稳赚、保证收益」——客户问收益照常回，只是不许替你承诺）。
- **安全词/黄灯**：对方打出红灯整轮拦下；黄灯是减速信号，提示词自动转为「先确认状态、不加码」。
- **专家库**（设置 →「人设与语气」→「打开专家库」，独立页面）：一个「专家」= 一份人设正文 + 头像 / 一句话简介 / 标签 / 分类 / 使用次数。
  - **浏览**：2 列卡片网格，可按分类抽屉筛选，可搜名字 / 简介 / 标签 / 正文；排序有「综合 / 最热 / 最新」三种。
  - **套用**：点卡片 →「用这个专家」，正文立刻写进设置里的人设（**设置里那段文本仍是唯一真源**，不另存「当前选了谁」），同时记一次使用次数（「最热」排序的数据源）。
  - **自建**：新建 / 编辑 / 重命名 / 复制 / 删除 / 导入导出（剪贴板）/ 恢复内置模板。
  - **内置 14 张**，覆盖五类：情感（网调·我是主、网调·我是奴、恋爱·刚认识、恋爱·冷战破冰）、销售（销售·跟单、销售·报价、销售·追尾款）、职场（向上汇报、同事协作、催进度）、客服（售后、投诉安抚）、日常（日常、家人·日常问候）。
  - **旧库自动升级**：v1 的 `personas.json` 会先备份成 `personas.v1-<时间戳>.json` 再原子写升级成 v2；之后新增的内置预设会自动补进来，而**你删掉过的预设不会复活**（`seeded[]` / `removed[]` 台账）。
  - **专家绑定（灰度，默认关）**：打开 `expert_binding_enabled` 后，只有该专家点名的技能会进提示词；关闭时装配链路与以前完全一致。
- **联系人专用人设**：知识库里每个联系人可以有自己的卡，压过全局人设；**联系人自己的「关系」也压过设置页的全局关系描述**。
- **专家目录（331 位，只读货架）**：随 APK 打包，按 22 个领域分类（技术工程 / 设计 / 市场营销 / 销售 / 金融 / 医疗 / 法务 / 学术…），来自 `MichengAI/dsh-agency-agents`。
  - 点「用这个专家」= 先入库再套用（热度记在库里那条上）；点「加入我的专家库」= 只入库不改当前人设。
  - 入库后与自建专家完全一样：能改名、改正文、删除、导出；已入库的那位不会在列表里再出现一份目录样品。
  - 每条的正文是**提炼卡**（称呼 / 关系 / 语气 / 主题 / 情境 / 三条规矩 / 两三句示例，约 250 字），只有它会进提示词；上游完整手册不进。
  - 上游更新：`python3 tools/gen_experts.py --src <repo>` 重生成 `app/src/main/assets/kb/experts.json`；`--check` 校验一致性。

- 填卡时界面实时回显「认出了什么」——认不出键是静默失败，这里必须当场说出来。

## 6. 知识库与记忆

- **笔记**：标题 + 正文 + 标签，可设「常驻」（每轮都带）或按对话内容命中（BM25 检索，最多带 5 条）。
- **主题收窄**：人设卡写了「主题：网调」，就只从标了「网调」的笔记里挑，装修带娃的笔记不会混进来当噪声。
- **语气样例**：标成「语气示例」的笔记作为 few-shot 原文带给写作模型（最多 3 条），只学语气不当事实。
- **文档导入**：PDF / Word(.docx) / EPUB / 网页直接吃，有文字层的直接抽，扫描件回落本机 OCR，长文自动分块成笔记。
- **领域卡**：把一个主题的笔记均衡采样预扫成一张设定卡，常驻提示词。
- **联系人档案**：名字 + 别名（跨 App 认出同一个人）+ 关系 + 备注 + 专用人设；聊天超过一定量后自动生成「过往摘要」。
- **聊天历史与台账**：**默认关闭**（不落盘需你明确打开）。打开后每轮注入最近历史；「会话台账」把整段历史预扫成一张结构化卡（称呼 / 关系 / 语气基线 / 在办的事 / 已明确的边界 / 固定说法），早期说过的约定不会因为滚出窗口而丢。

## 7. 技能系统（Agent Skills）

按 Anthropic 的 Agent Skills 规范，一个技能就是一个 `SKILL.md`（可带参考资料），打成 zip 导入，本机存储、默认关闭、逐个启用。

- 内置可选包「**狗头军师**」（MIT，上游 shengjidaguai-china/goutoujunshi）：40+ 篇恋爱 / 接话 / 夸人 / 冲突修复 / 高情商拒绝 / 分手复合方法论，附依恋理论、同意边界等知识参考。
- 三层注入：技能目录每轮常驻（L1）；对话命中时正文进提示词（L2）；它自带的参考资料再按本轮对话挑两三篇（L3）。全部本地检索，不花额外 token。

## 8. 接口与模型

- **三路独立**：判断（Jev/TypeSafe 协议或 OpenAI 聊天协议）、回复（任何 OpenAI 兼容）、视觉（仅设置页连通测试用，OCR 走本机 ML Kit，不经过视觉接口）；复查可另配第四路，留空沿用回复路由。
- **预设**：DeepSeek（判断自动切聊天模式）、通义千问兼容模式、OpenRouter（默认，Jev 判断模型 `typesafe/jev-1.13`）、Bocha / TypeSafe / Vercel / Zen，或自定义完整 URL。
- **可调参数**：温度、频率/新话题惩罚、请求超时、候选条数（1–3）、流式输出（边生成边显示）、回复语言（跟随对方 / 中文 / 英文）、回复长度（短 / 标准 / 详细）。
- 密钥用 Android Keystore AES-GCM 加密存储，界面里只显示掩码；不进日志、不进 git。

## 9. 安全与边界

- 绝不自动发送、绝不点发送按钮、不碰转账红包收款码。
- 请求前的安全闸门：违法内容、自伤自杀、未成年×亲密（同时出现即拦）、约好的安全词、你写下的硬边界——拦下时在卡上说明原因，不是静默失败。
- 提示词层的硬性禁止（任何情况下有效）：不编造没发生过的事、不提对方没提过的人和计划、不冒充他人、不替你许诺转账点链接。
- 聊天内容只发往你自己配的模型接口；知识库、历史、人设全部本机 `filesDir`，设置页一键清空。

## 10. 兼容性与 root 增强（可选）

- 国产手机的「设置里开着、服务其实没跑」问题：首页判据是**服务真的连上来**，不是设置项；root 设备（KernelSU 等）一键修复无障碍 / 悬浮窗 / 写系统设置权限 / 省电白名单，覆盖安装后自动修；无 root 时核心路径照常可用，只是权限要手动点。
- 悬浮窗、通知常驻（带「唤出助手」「重新生成」）、按应用静音自动分析、会话白名单。

## 11. 透明度

- 每一轮在 `files/jev-trace.log` 留一行级别的事实行（读了什么、命中几条、降级原因），`adb exec-out run-as com.jev.probe cat files/jev-trace.log` 可查。
- 采集来源分级标注（无障碍节点 / 注入 / OCR / 手动截屏），卡片上如实显示。

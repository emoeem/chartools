# Jev for WhatsApp 隐私说明

本文适用于本目录中的 Android 应用（`com.jev.overseas`）。仓库中的国内版应用另有自己的[隐私政策](../cn/PRIVACY.md)。

本项目没有服务器，也不会收集数据。应用只会使用你提供的 API 密钥与 OpenRouter 通信。

## Jev 会读取哪些内容

- 仅读取 WhatsApp（`com.whatsapp`），且只有在你点击 Jev 气泡后才会读取。
- 只读取屏幕上当前打开的聊天。Jev 会在该聊天中向上滚动，收集最近约 24 条消息；点击“继续向前读取”后，读取量约增加一倍。
- 消息文本、发送者（你或对方），以及消息行是否为照片、文档、语音消息或其他媒体。Jev 不会打开媒体内容。
- 不截屏、不读取其他应用、不访问联系人列表或 WhatsApp 数据库。

WhatsApp 未显示在屏幕上时，无障碍服务只接收窗口变化事件，用于显示或隐藏气泡。

## 哪些内容会离开手机

每一轮都会向 `openrouter.ai` 发送 HTTPS 请求，由 OpenRouter 转发给你配置的模型提供方（默认情况下，Jev 模型使用 TypeSafe，回复起草使用 DeepSeek）：

| 请求 | 包含的内容 |
|---|---|
| 分析 | Jev 读取的消息，以及你选择的场景和关系 |
| 起草 | 相同的消息、分析结果、你的目标和你填写的补充信息 |
| 检查 | 消息、你的目标和每条起草出的回复 |
| 密钥检查 | 仅 API 密钥，用于显示剩余额度 |

发送内容可能包含对方的消息。OpenRouter 和模型提供方会根据各自的政策处理这些数据：[OpenRouter 隐私政策](https://openrouter.ai/privacy)。你可以在“设置 › 模型”中选择其他模型。

不会向其他任何地方发送数据。应用不含分析、崩溃报告或遥测功能。唯一的 Android 权限是 `INTERNET`。

## 哪些内容保留在手机上

以下数据保存在应用私有存储中，不包含在云备份或设备迁移数据中：

- 你的 OpenRouter 密钥：使用保存在 Android Keystore 中的 AES-GCM 密钥加密。保存后不会再次显示完整密钥；设置页面只显示“sk-or-…”和末尾四个字符。
- 你的设置（模型、拼写方式、气泡位置、“打开时分析”）。
- 每个已设置的聊天对应的场景和关系：通过聊天标识与每次安装随机生成的盐值计算 SHA-256 哈希后保存，不保存联系人姓名。
- 最近 1000 条诊断事件日志：包括标识、数量、评分、耗时和错误类型；绝不记录消息文本、姓名、回复、你输入的目标、密钥或聊天哈希。详见[诊断与问题报告](docs/DIAGNOSTICS.zh-CN.md)。该功能默认关闭，你可以在设置中开启、关闭或清除日志。

聊天文本和起草出的回复只会在当前轮次中保留于内存（最长 15 分钟），不会写入存储。

## 你可以控制什么

- 在你点击气泡之前，Jev 不会读取任何内容。
- “清除已记住的聊天”会删除所有已记住的场景。
- 只有在你点击“报告问题”或“分享报告”时才会生成问题报告，报告只会发送到你选择分享的地方。只有勾选“包含目标和回复内容”后，报告才会加入目标和回复。
- 移除密钥、关闭无障碍服务或卸载应用都会停止所有操作。卸载应用会删除所有已存储数据。

## 发送消息

Jev 绝不会发送消息。“填入”会先确认当前仍是同一个聊天，再将选中的回复写入 WhatsApp 输入框；是否发送由你决定。
